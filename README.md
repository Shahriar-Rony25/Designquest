# 🎨 DesignQuest

**Level Up Your Design Skills & Portfolio**

DesignQuest is a gamified creative learning and portfolio platform built with **Next.js (App Router)**, **Prisma ORM**, and **PostgreSQL (Supabase)**. Creators can complete interactive design missions, earn XP and level up, customize their creator profile, and showcase compressed design projects in a persistent gallery.

🌐 **Live Demo:** [designquest-rho.vercel.app](https://designquest-rho.vercel.app)

---

## ✨ Features

* **Gamified Progress & XP System:** Track total XP, creator rank/level, and completed design missions across sessions.
* **Persistent Portfolio & Community Gallery:** Upload and showcase Logos, Branding, Posters, UI/UX, Illustrations, and Social Media designs backed by PostgreSQL via `/api/portfolio`.
* **Client-Side Image Compression:** Automatically resizes and compresses uploaded images using the HTML5 Canvas API before upload for fast performance and reliable storage.
* **Responsive Full-Frame Media Modal:** View complete design works with category tags, descriptions, likes, and community comments without edge clipping.
* **Real-Time Profile Synchronization:** Edit your creator username and bio in your profile and see portfolio authorship update dynamically across the app.

---

## 🛠️ Tech Stack

* **Framework:** Next.js 16 (App Router)
* **Frontend:** React, Custom CSS
* **ORM & Database:** Prisma ORM + PostgreSQL (Supabase)
* **Deployment:** Vercel (CI/CD via GitHub)
